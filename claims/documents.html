01 · Выберите свой комплект

Одно задание охватывает все счета. Для самопроверки можно вести отдельный чек-лист для каждого счёта; ZIP по всем счетам загружается в общую папку из задания. При смене вида или направления отметки сохраняются отдельно. Данные доступны в этом браузере, в этом профиле и по тому же адресу страницы.

Браузер не разрешает сохранение. Чек-лист работает до закрытия страницы. При необходимости распечатайте чек-лист перед выходом.
02 · Выгрузка через обработку 1С

Из 1С в папку претензии

Сначала выгрузите пакет по всем счетам из задания, затем сверьте его с чек-листом ниже.

Куда загружать: ZIP из 1С в «Файлы для подготовки претензии». Материалы, которых нет в выгрузке, в «Дополнительные подтверждающие документы». Обе ссылки находятся в вашем задании.

  1. Откройте общее задание

    В задании «Сбор документов для претензии» найдите блок «Ссылки на счета для копирования». Скопируйте все ссылки из этого блока: документы нужны по всем перечисленным счетам.

  2. Откройте обработку в 1С

    На начальной странице 1С перейдите: «Обработки → Дополнительные обработки → Сбор документов претензии».

  3. Вставьте ссылки на все счета

    Нажмите «Отбор по ссылкам счетов». Вставьте скопированные ссылки одним блоком в окно «Навигационные ссылки счетов» и нажмите «ОК».

  4. Проверьте список и скачайте архив

    Нажмите «Обновить». Проверьте дерево найденных документов и флажки напротив нужных файлов. Нажмите «Скачать выбранные» и сохраните ZIP-архив. Внутри документы сгруппированы по договору и счетам; также формируется реестр выгрузки.

  5. Загрузите ZIP в Битрикс24

    Вернитесь в своё задание и откройте ссылку «Файлы для подготовки претензии». Загрузите туда сохранённый ZIP-архив и дождитесь окончания загрузки.

  6. Сверьте комплект и добавьте недостающее

    По перечню необходимых документов проверьте, что собрано по каждому счёту. Состав ZIP зависит от файлов в 1С, поэтому выгрузка может содержать не весь комплект. Документы и переписку, которые не вошли в выгрузку, загрузите через ссылку «Дополнительные подтверждающие документы» из задания.

Подробная инструкция по обработке в 1С (Outline) ↗
Обработка выгружает документы, которые найдены в 1С. Скачанный архив сам по себе не подтверждает полноту: проверьте документы по каждому счёту. По ДЗ обязательными остаются 5 позиций из чек-листа; остальные необязательны.

04 · Как завершить сбор

От чек-листа к заданию

  1. Проверьте документы всех счетов

    Откройте «Файлы для подготовки претензии» из своего задания. Убедитесь, что ZIP загрузился полностью, открывается и содержит документы по всем указанным счетам. Дополнительные файлы проверьте в «Дополнительные подтверждающие документы». Сверяйте отметки чек-листа с содержимым файлов по нужному счёту.

  2. Проверьте, что осталось собрать

    Нажмите «Не собраны». Если нужного документа нет в выгрузке 1С, найдите его по подсказке «Где взять документ» и загрузите в «Дополнительные подтверждающие документы». Отметьте документ после загрузки.

  3. Завершите задание в Битрикс24

    При наличии сведений заполните общие поля «Комментарий Контрагента» и «Комментарий Сотрудника». Сведения по разным счетам разделите абзацами, указывая номер нужного счёта. Нажмите «Документы загружены» один раз, когда комплект собран по всем счетам.

Обязательная позиция остаётся несобранной, пока документ отсутствует. Отмечайте её после проверки документа в загруженном ZIP или после загрузки недостающего файла в «Дополнительные подтверждающие документы».

Правила хорошего комплекта

  • Три опоры: основание требования, документ о событии и подтверждение суммы.
  • Имена файлов: Тип_Номер_Дата, например Счет_1234_15.10.2026.pdf. Используйте читаемые PDF или JPG и приложите опись.
  • УПД: приложите подписанный экземпляр либо доказательство направления, если не подписан.
  • Перевыставляемый расход: договор со ставкой, заявка на отправку, акт или УПД с расшифровкой, счёт и платёжное поручение.
  • Суммы: сверяйте с 1С. По исходной инструкции расхождение свыше 1 рубля требует устранения до передачи комплекта.
  • Досылка: по исходной инструкции не позднее одного рабочего дня после запроса юриста, в существующую папку.
Сроки из исходной инструкции

Сбор по исходящей претензии: 3 рабочих дня. По входящей: 5 рабочих дней. Ответственность за полноту и срок возложена на руководителя отдела. Проверяйте также срок полученного задания. Эти сроки приведены как внутренние правила исходного документа, а не как подтверждение настройки таймеров БП.
