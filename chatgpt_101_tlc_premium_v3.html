Контроль качества

Простая проверка результата

Перед использованием важного ответа задайте три вопроса.

3 мин

Не является ли уверенное утверждение предположением?

3. Можно проверить?

Сверяется ли важная информация с документом или первоисточником?

Промпт для самопроверки

11
Данные компании

Безопасность

Передавайте только ту информацию, которая действительно нужна для решения задачи.

3 мин
i
Рабочие задачи выполняйте в корпоративной рабочей области ChatGPT

Перед загрузкой файла задайте себе вопрос: нужна ли ИИ вся эта информация для решения задачи?

Можно использовать

  • рабочие тексты без лишних секретов;
  • обезличенные примеры;
  • документы, необходимые для конкретной задачи.

Сначала подумайте

  • ФИО и контакты;
  • реквизиты клиента;
  • внутренние данные, которые не нужны для задачи.

Не передавайте

  • пароли и одноразовые коды;
  • API-ключи и секретные токены;
  • данные банковских карт;
  • учетные данные пользователей.
